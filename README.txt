# GP Editor Offline — v0.3.0

Windows 11 x64用のオフラインGP-5 / GP-50エディターです。機種切替とUSB / Bluetoothに対応します。

## 起動と接続

ZIPをフォルダーごと展開し、GP5-Editor-Offline.exeを起動してください。DLL・resources・localesも必要です。
ブラウザーやNode.jsの別途インストールは不要です。インストーラー、管理者権限、ファームウェア更新も不要です。

1. Valeton Suiteや他のGP-5 / GP-50エディターを終了します。
2. 上部の機種でGP-5 / GP-50、USB / Bluetoothで接続方式を選び、対応するConnectボタンを押します。
3. Bluetoothの場合は本体のBluetoothを有効にし、選択機種と一致するGP-5 / GP-50を選びます。スマートフォン等の接続は終了してください。
4. 接続後のパラメーター操作は本体へ反映されます。本体に保存は確認と自動バックアップ後に現在のパッチを上書きします。
5. 上部のPCに保存…で、未保存の編集を含む現在のパッチを.prstファイルに保存できます。

## PC保存・読み込み・名前変更

- PCに保存…: 本体の現在の音色を読み取り、保存先を選びます。名前に空白がある場合や短い名前も正しく保存します。
- PCから読み込み…: 選択した機種用の.prst（GP-5:507バイト / GP-50:552バイト）を選び、名前と上書き先を確認します。読み込みは本体の現在のスロットを上書き保存します。
- 名前を変更…: 半角英数字・記号で1〜10文字の名前を入力します。本体の名前を変更し、未保存の音色編集はそのまま保ちます。
- バックアップを開く: 上書き前に保存した.prstを表示します。editingは未保存の編集を含む内容、storedは本体に保存されていた内容です。復元するときは目的のスロットを選んで.prstを読み込んでください。

バックアップは %APPDATA%/gp5-offline-desktop/patch-backups/ に保存します。アプリのZIPやソースには含みません。
読み込み・本体保存の上書き前に両方のバックアップを保存・検証します。名前変更では変更前の編集内容をバックアップします。保存に失敗した場合は本体の上書きを開始しません。
送信は1フレームずつ応答を待ち、終了後に本体を読み戻して全パラメーターと名前を照合します。失敗時の自動再試行はありません。
処理中は本体のスイッチ操作や電源・USBの切断を避けてください。

.prstにはUser IR/SnapToneの音声・モデル本体は含まれません。同じ本体スロットのデータを参照するため、別の本体では音が異なる場合があります。
選択機種と異なる形式、破損ファイル、未対応のエフェクト構成は読み込み前に拒否します。

## 本体との自動同期

上部の本体の変更を自動同期は初期状態で有効です。本体のパッチ選択・パラメーター・スイッチ・並び順・音量・CTLを読み取り、画面へ反映します。
目安はUSBで約1.5秒、Bluetoothで約3秒間隔です。名前は変更通知と定期確認でも更新します（最大約10秒）。
ファイル・本体保存中は同期を一時停止し、PCでの編集操作中に届いた古い読み取り結果は画面に適用しません。
この同期は読み取り専用で、PCファイルの自動上書きはしません。不要な場合はチェックを外してください。

起動だけでは接続や送信を行いません。NAM変換・導入、ファームウェア更新の機能はありません。
コード署名はありません。最初の実機確認前にはプリセットをバックアップしてください。

## GP-50対応と調査資料

GP-50の機種別カタログ・パッチ形式・グローバル画面を復元しました。GP-5からGP-50への自動変換は行わず、異機種ファイルは読込前に拒否します。
GP-50のCTL・テンポのライブ変更は実機検証待ちのため無効です。既存ファイルのFS・EXP設定は保持して保存します。
GP-50はファイルに含まれる16文字の名前を読出し・保持します。名前変更ダイアログは確認済みの10文字のコマンド形式を使います。
Bluetoothは機種が分かる機器名を選んでください。不明な名称・異機種は接続を拒否します。

IR/SnapTone管理などの取り込み候補、ライセンス、実機確認項目は [機能整理](FEATURE_REVIEW.md) を参照してください。今回IR/SnapToneの転送やNAM変換は追加していません。

## ソースから実行・ビルド

Node.js 24以上を使用します。初回の依存取得にはネット接続が必要です。

powershell
npm ci
npm run brand
node scripts/check-gp5-export.cjs
node --test scripts/test-presets.cjs
npm start
npm run smoke
npm run package


package.jsonのversionからHTMLとウィンドウの表記を同期します。ビルド出力は../../outputs/<version>/です。
PNG・ICO・SVGアイコンを同梱しているので、通常のビルドでアイコン生成は不要です。
smokeは非表示起動とポート列挙、合成データの保存、合成BLE機器選択を検証します。実機へのコマンドは送りません。
制限付き開発環境でのテスト条件と未確認事項はVALIDATION.mdをご確認ください。
